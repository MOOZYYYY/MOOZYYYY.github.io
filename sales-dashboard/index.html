What this means for the business

    How it's built: 541,909 raw invoice lines → SQLite star schema (fact_sales, dim_customer, dim_product, dim_date) → 13 SQL queries (CTEs, window functions: LAG, NTILE, running sums) → this page. Headline KPIs are cross-checked against an independent pandas calculation.

    Definitions: revenue counts product lines only (no postage or fees) and subtracts cancellations; an order is a distinct non-cancelled invoice; average order value is per invoice, not per line. Data generated .
